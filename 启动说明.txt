LiteCraft Launcher

双击 LiteCraft Launcher.exe 启动。

首次启动
- 同意 PCL 的用户协议。
- 在启动页的“游戏用户名”输入名字（必填，1-16 个字符）。
- 在版本列表选择 LiteCraft 26.3，点击“启动游戏”。

下载与安装
- 下载页使用 PCL 原版页面，但原版游戏的版本列表来自本项目的 GitHub 配置，不再读取 Mojang 的完整版本列表。
- 配置会依次尝试 GitHub 官方 raw 地址与镜像；每一份内容都用启动器内置的 SHA-256 校验，校验不通过会拒绝使用，防止镜像劫持。
- 选择 LiteCraft 26.3 后进入 PCL 原版安装页。安装页只保留原版下载，Forge、Fabric、OptiFine 等附加组件暂时隐藏。
- 安装时由 PCL 原生流程下载 26.3 的客户端、依赖库和资源文件，进度与 PCL 一致。
- 原版文件下载完成后，启动器从 GitHub Release 下载 LiteCraft 核心文件（同样校验 SHA-256），解压到 LiteCraft 目录，再调用后端复用 PCL 已下载的文件准备资源。
- 资源准备完成后，LiteCraft 26.3 会自动加入版本列表，可以直接启动。
- 如果发布包已经带有 LiteCraft\resources\26.3，启动器会直接使用，不需要重新准备。

设置
- 启动器设置、版本设置、窗口大小等均为 PCL 原版页面。
- LiteCraft 启动沿用 PCL 的窗口大小和全屏设置。
- 视距在游戏内“选项 → 视频设置”调整，上限 512 区块；在视距滑块上 Shift+点击可直接跳到 512。

文件
LiteCraft\litecraft.exe              游戏本体
LiteCraft\LiteCraft-Launther.exe     资源准备后端
LiteCraft\resources\26.3             准备好的游戏资源（安装后生成）
LiteCraft\prepare                    资源准备组件
.minecraft\versions\LiteCraft 26.3   PCL 版本（安装或首次启动后生成）
